# Contributing

MEE is a **commercial product** of Deepsim-AI. This repository is published
primarily so customers and the public can inspect the code, verify signed
releases, and report issues. It is **not** an open-source project in the
contribution-acceptance sense.

## What we do welcome

- **Bug reports** — via [GitHub Issues](https://github.com/Deepsim-AI/multimodal-emotion-engine/issues).
  Please include MEE version, OS/hardware (e.g. Jetson AGX Orin), Python
  version, and a minimal reproduction.
- **Security reports** — **do not** open a public issue. See [`SECURITY.md`](SECURITY.md)
  and email `security@deepsim.com`.
- **License / licensing questions** — email `licensing@deepsim.com`.

## What we do not accept

- Pull requests that modify the core `mee/` package, licensing, or model
  pipeline. The engine is developed internally by Deepsim-AI.
- Requests to change the license or add open-source licenses to the core
  package. The core is distributed under the Deepsim Commercial Software
  License.

## If you believe you have a legitimate fix

Open an issue describing the problem and the fix you propose. A Deepsim-AI
engineer will review it and, if valid, may implement it internally. We
appreciate the report either way.

## Code of conduct

Interactions in issues, discussions, and any other public space are governed
by our [Code of Conduct](CODE_OF_CONDUCT.md).
